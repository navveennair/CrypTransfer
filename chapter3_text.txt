[302]: 3.2   Methodology Choice and Justification

[303]: CrypTransfer will be developed based on a combination Agile and Waterfall methodology. It is a mix of both methods since the Waterfall method focuses on detailed problem statement, literature review, requirements specification with a highlevel system design. With the waterfall method, the system can be defined more clearly regarding its purpose. With Agile on the other hand, an iterative approach can help build the core of the system faster by breaking it down into cycles or sprints, further allowing software to be developed faster. This methodology ensures that the system’s deliverables are met as CrypTransfer is being developed.

[328]: 3.4    Technology Used Description

[329]: The development of the CrypTransfer secure file transfer system relies on carefully selected software technologies. Each playing a crucial role in realizing the project's objectives.

[330]: 3.4.1   Dart

[331]: There are numerous benefits for Dart to be the implementation language for CrypTransfer. Since Pointycastle is made with Dart, the frontend and backend can be written in a single language which equals to reduced development time. It's cross-platform, so the same code will run in Android and iOS. Via large cryptographic libraries like Pointycastle, the developer can easily provide cryptographic functionality such as file encryption, transfer protocols and data processing which are required in the system.

[332]: 3.4.2    Firebase

[333]: Firebase is the backend database management system for CrypTransfer and its role would be important for storing and managing structured data that is required to the application's operation beyond simple file content. This could include storing user profiles and file’s metadata details.

[335]: 3.4.3   Visual Studio Code

[336]: The main IDE of CrypTransfer system is Visual Studio Code. This environment has many tools to speed up coding and simplify it. This makes it an easy task to write code efficiently, get productive codes for developers who use Flutter and Pointycastle by providing code completion tools, a built-in program debugger and connection to version control systems in an instant and many extensions which can help. This makes it a strong weapon for developing, testing and keeping Dart code.

[339]: 3.4.4   Pointycastle

[340]: Pointycastle is a cryptographic library for CrypTransfer as it provides the fundamental low-level cryptographic primitives to achieve the project's core objective of secure file transfer. Implementations of encryption such as AES for regular encryption and RSA for the keys that will lock the AES encryption for security using Pointycastle. Pointycastle's reliability and easy-to-use API for generating keys, encrypting data and decrypting data is crucial for building the security backbone of CrypTransfer, also ensuring the confidentiality and integrity of the information being transferred.

[341]: 3.4.5   GitHub

[342]: GitHub is largely used to strongly back up and carefully track every change in code. The practice of regularly "pushing" the local project codebase to a remote GitHub repository establishes a secure offsite backup, mitigating risks associated with local hardware failures or accidental data loss. This enables straightforward reversion to previous stable states if required, allows for a comprehensive understanding of the project's evolution, and ensures a well-organized historical record of development efforts. Sticking to such a disciplined approach helps ensure the code is safe and secure.

[343]: 3.4.6   Dart

[344]: CrypTransfer was developed in Dart, as it is easy to read, write and has good support for encryption and cross-platform development across Firebase and Flutter. Being high-level, interpreted, it is quick to develop in, with fewer lines of code required than in other compiled languages. The cryptographic library itself has native support for AES and RSA encryption allowing secure cryptographic operations without implementing algorithm.
