# Quick Task 260607-b3m: Fix RSA Key Vault first-time generate dialog

## Problem

`_onRegenerate()` always shows "Regenerate RSA Keys?" title, "Your old private key will be replaced"
message, and "Regenerate" button label — even on first-time generation when `hasKey` is false.
`hasKey` lives in `_buildVaultBody` scope but never reaches `_onRegenerate`.

`regenerateKeyPair()` in `AuthRepository` is correct: it uses a 3-doc WriteBatch that updates
`publicKey` in Firestore, writes an audit log, and stamps `keyVaultCreatedAt`. No changes needed
in the repository layer.

## Task 1 — Pass `hasKey` to `_onRegenerate` and branch dialog content

**File:** `lib/presentation/vault/rsa_key_manager_screen.dart`

### Change 1 — Method signature

```dart
// Before:
Future<void> _onRegenerate() async {
// After:
Future<void> _onRegenerate({required bool hasKey}) async {
```

### Change 2 — `_showConfirmDialog` call inside `_onRegenerate`

Replace the hardcoded dialog args with `hasKey`-branched values:

```dart
final confirmed = await _showConfirmDialog(
  icon: hasKey ? Icons.refresh_rounded : Icons.vpn_key_rounded,
  iconColor: cs.primary,
  title: hasKey ? 'Regenerate RSA Keys?' : 'Generate RSA Keys?',
  message: hasKey
      ? 'This will generate a new RSA-2048 keypair.\n\n'
          'Your old private key will be replaced on this device '
          'and your public key in Firestore will be updated.\n\n'
          'Active sessions will be notified automatically.'
      : 'This will generate an RSA-2048 keypair for your account.\n\n'
          'Your public key will be stored in Firestore so senders '
          'can encrypt files for you.',
  confirmLabel: hasKey ? 'Regenerate' : 'Generate',
  confirmColor: cs.primary,
);
```

### Change 3 — Call site in `_buildVaultBody`

```dart
// Before:
onPressed: _regenerating ? null : _onRegenerate,
// After:
onPressed: _regenerating ? null : () => _onRegenerate(hasKey: hasKey),
```

**Verify:** `flutter analyze` — no issues.
