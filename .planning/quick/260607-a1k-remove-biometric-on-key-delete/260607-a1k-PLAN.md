# Quick Task 260607-a1k: Remove redundant biometric prompt on key delete

## Goal

`RsaKeyManagerScreen._onDelete()` calls `BiometricHelper.authenticate()` before showing the
confirmation dialog. The vault entry gate in `initState → _authenticate()` already verified
the user. The second prompt is redundant and confusing — remove it.

## Task 1 — Remove biometric gate from `_onDelete`

**File:** `lib/presentation/vault/rsa_key_manager_screen.dart`

**Action:** Delete lines 127–128:
```dart
final gateOk = await BiometricHelper.authenticate('Confirm: Delete RSA Keys');
if (!gateOk || !mounted) return;
```

**Verify:** `_onDelete` goes straight to `_showConfirmDialog` after the null-uid guard.
