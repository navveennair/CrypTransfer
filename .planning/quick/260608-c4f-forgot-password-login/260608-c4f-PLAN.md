# Quick Task 260608-c4f: Forgot Password

## Goal
Add a "Forgot password?" link to the login screen. Since login is username-based, the flow is:
1. User taps "Forgot password?"
2. Bottom sheet opens with a username input field
3. User submits → Firestore lookup finds their email → `FirebaseAuth.sendPasswordResetEmail` fires
4. Success/error feedback shown inline

## Context
- Login uses username (not email). `loginWithUsername` already does the Firestore query to resolve email.
- Firebase `sendPasswordResetEmail(email)` needs the actual email address.
- No new screen needed — a bottom sheet keeps it lightweight.

---

## Task 1: Add `sendPasswordResetEmail` to AuthRepository

**File:** `lib/data/repositories/auth_repository.dart`

**Action:** Add method after `loginWithUsername`:

```dart
Future<void> sendPasswordResetEmail(String username) async {
  final query = await _db
      .collection(FirebaseConstants.users)
      .where('username', isEqualTo: username)
      .limit(1)
      .get();
  if (query.docs.isEmpty) {
    throw AuthException('No account found with this username.',
        code: 'username-not-found');
  }
  final email = (query.docs.first.data()['email'] as String?)?.trim() ?? '';
  if (email.isEmpty) {
    throw AuthException('Account data is corrupted.', code: 'account-data-corrupted');
  }
  await _auth.sendPasswordResetEmail(email: email);
}
```

**Verify:** Method exists in auth_repository.dart, takes `String username`, does Firestore lookup then calls `_auth.sendPasswordResetEmail`.
