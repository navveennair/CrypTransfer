# Quick Task 260608-a4b: Delete User Audit Logs

## Goal

Write a `scripts/reset_user_audit.js` Node.js script (using firebase-admin) that deletes all audit log data associated with a given user UID so they can start fresh.

## Collections to clean

| Collection | Path | How to find |
|---|---|---|
| Personal audit logs | `users/{uid}/audit_logs` | Subcollection — delete all docs |
| RSA key manager | `users/{uid}/rsa_key_manager` | Subcollection — delete all docs |
| Global transfer logs | `transfer_logs` | Query where `participants` array-contains `uid` |
| Security audit log | `security_audit_log` | Query where `uid == uid` (if field exists) |

## Tasks

### Task 1: Write reset_user_audit.js script

**File:** `scripts/reset_user_audit.js`

**Action:** Create Node.js script that:
1. Reads UID from CLI arg (`node reset_user_audit.js <UID>`)
2. Deletes all docs in `users/{uid}/audit_logs` subcollection
3. Deletes all docs in `users/{uid}/rsa_key_manager` subcollection
4. Queries `transfer_logs` where `participants` array-contains `uid`, deletes matches
5. Prints count of deleted docs per collection

**Verify:** Script file exists, has correct structure, handles errors gracefully

**Done:** `scripts/reset_user_audit.js` created with usage instructions in comments
