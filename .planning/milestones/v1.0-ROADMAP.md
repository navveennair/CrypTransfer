# Milestone v1.0: Pre-Viva Thesis Demonstration Build

**Status:** ✅ SHIPPED 2026-07-05
**Phases:** 02-11 (plus decimal insert 07.1)
**Total Plans:** 40

## Overview

CrypTransfer's first complete, security-hardened build: a zero-remanence, end-to-end encrypted peer-to-peer file transfer app (Flutter + Firebase), built as a thesis demonstration platform at the University of Hertfordshire. This milestone covers the full arc from receiver-side hardening through the neutral handshake connection model, synchronized crypto readiness, reactive session cleanup, Android release packaging, navigation/session-integrity hardening, and admin dashboard security.

## Milestone Summary

**Decimal Phases:**
- Phase 07.1: Layer Decoupling Refactor (inserted after Phase 07 to close an architectural coupling violation before continuing)

**Key Decisions:**
- Neutral Handshake Model (Phase 05) decouples connection establishment from sender/receiver role assignment — proposerId/partnerId semantics, deferred role selection
- Receiver-as-master session control — only the receiver triggers cleanup; sender reacts to Firestore deletion events (Phase 04), later evolved into a synchronized 4-turn destruction protocol
- All Firestore access centralized into Repositories (Phase 07.1) — no direct `FirebaseFirestore.instance` calls in the presentation layer
- Biometric-gated RSA Vault as the sole key lifecycle surface (Phase 03)
- AdminGuard + FutureBuilder-based admin dashboard hardening (Phase 11) over always-on Firestore streams, for both security and read-cost efficiency
