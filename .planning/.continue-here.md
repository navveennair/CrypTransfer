<decisions_made>

- TofuService delegates fingerprint computation to `AuthRepository.computeFingerprint()` — keeps SHA-256 in one place
- Display fingerprint = first 16 hex chars uppercase grouped as "AB12 CD34 EF56 7890" (matches RSA Key Manager display)
- Storage keys: `tofu_pin_{uid}` (fingerprint), `tofu_ver_{uid}` ("1" if verified)
- firstContact auto-pins silently — user gets amber nudge but transfer is not blocked
- keyChanged shows non-dismissible dialog — user must choose "Re-verify & Trust" or "Cancel" (which reverts to waiting)
- repin() clears verified flag — user must re-verify new key explicitly
- No Firestore changes needed — everything is local FlutterSecureStorage
</decisions_made>
