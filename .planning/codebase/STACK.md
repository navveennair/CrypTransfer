# Tech Stack
_Last updated: 2026-06-15_

## Language & Runtime

**Primary:** Dart `^3.12.0` — all application logic, crypto, UI, and repository layer

**Secondary:** Kotlin (JVM 17) — Android native entry point (`MainActivity.kt`) for `FLAG_SECURE`, `MethodChannel` bridges, and file system access

**Flutter SDK:** `>=3.44.0` (required minimum; Impeller backend / OpenGLES renderer active)

**Platform target:** Android (primary). iOS, macOS, Web, and Windows configs present in `lib/firebase_options.dart` but are not actively maintained.

**Android SDK:** `compileSdk` = Flutter default, `minSdk` = Flutter default (effectively API 21 per `flutter_launcher_icons` config), `targetSdk` = Flutter default

---

## Framework

**Flutter** `>=3.44.0` — cross-platform UI with Material 3 enabled

- Rendering: **Impeller backend (OpenGLES)** — enabled for performance and to mitigate UI-layer side-channel attacks
- State management: `provider ^6.1.5+1` — `ChangeNotifierProvider` wrapping `ThemeService` at app root (`lib/main.dart`); no other global state management library
- Theme: Custom GitHub Dark palette defined in `lib/app_theme.dart`; Material 3 `ColorScheme` throughout; light/dark/system modes persisted via `shared_preferences`

## Build & Tooling

**Build system:** Flutter / Gradle (Kotlin DSL)

**Release build:**
- R8 minification enabled (`isMinifyEnabled = true`, `isShrinkResources = true`)
- Signed with `android/key.properties` keystore; falls back to debug signing if file absent
- ProGuard keep rules in `android/app/proguard-rules.pro`
- Build command: `flutter build apk --release` or `flutter build appbundle`

**Dev commands:**
```bash
flutter run                    # Debug run on connected device
flutter analyze                # Static analysis (must pass with 0 issues)
flutter test                   # Run test suite
flutter build apk --release    # Release APK
```

**Automation scripts** (located in `scripts/`):
- `scripts/silent_guardian.ps1` — headless security scanner; checks scanner rules against `lib/`, writes audit report to Obsidian vault
- `scripts/update_status.ps1` — runs `flutter analyze`, syncs Known Open Issues in `CLAUDE.md`
- `scripts/security_audit_report.dart` — generates structured security audit Markdown
- `scripts/write_obsidian_report.dart` — writes daily summary to Obsidian vault
- `scripts/launch_guardian.bat` — Windows Task Scheduler launcher for `silent_guardian.ps1`

**CI/CD:** No CI pipeline configured. All builds are local. No `Makefile`, no GitHub Actions, no Fastlane.

**Lockfile:** `pubspec.lock` — present and committed.
