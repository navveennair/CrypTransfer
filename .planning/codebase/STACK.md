- flutter_secure_storage 10.0.0 - Encrypted at-rest storage of RSA private keys in platform keystore (Android: Keystore; iOS: Keychain); prevents plaintext disk exposure

**Critical (Firebase):**
- firebase_core 4.6.0 - Firebase SDK initialization and project configuration
- firebase_auth 6.3.0 - Email/password and Google Sign-In authentication; returns JWT tokens for Firestore rule evaluation

- firebase_storage 13.2.0 - Encrypted file payload storage (sender uploads ciphertext, receiver downloads for decryption)
