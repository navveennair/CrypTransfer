## Data Storage

**Databases:**
- Cloud Firestore (cloud-hosted NoSQL)
  - Connection via `FirebaseFirestore.instance`
  - Collections:
    - `users/{uid}` - User profiles with auth metadata, RSA public key, session state
    - `transfers/{transferId}` - Active file transfer metadata (senderId, receiverId, IV, encrypted AES key, receiverStatus)
    - `transfer_logs/{logId}` - Immutable audit log per transfer (append-only)
    - `neutral_handshakes/{handshakeId}` - Connection-layer symmetric proposals (proposerId_partnerId doc ID pattern)
    - `handshakes/{handshakeId}` - Session-layer RSA key exchange per sender-receiver pair (receiverId, senderId, publicKey, status fields)
    - `users/{uid}/notifications/{notifId}` - User notifications for handshake events
    - `users/{uid}/audit_logs/{logId}` - Per-user immutable transfer history
    - `users/{uid}/friendships/{friendId}` - Bilateral friendship status (proposed/accepted/rejected)
    - `users/{uid}/profile/{prefId}` - User preferences and security settings
    - `users/{uid}/rsa_key_manager/{logId}` - Append-only RSA key lifecycle audit trail
  - Security: Firestore security rules at `firestore.rules` enforce authentication, ownership, and role-based access

**File Storage:**
- Firebase Storage (encrypted file payloads)
  - Path: `transfers/{transferId}/encrypted_file` - AES-256-GCM ciphertext
  - Sender uploads via `SendScreen._encryptFile()` → `TransferProgressScreen._startUpload()`
  - Receiver downloads via `DecryptScreen` after decryption readiness

**Caching:**
- Local device caching only (no Redis/Memcached)
  - `shared_preferences` 2.5.5 - User preferences, app state
  - `flutter_secure_storage` 10.0.0 - RSA private key at-rest encryption

## Android Native-Dart Bridge

**MethodChannel: `com.example.cryptransfer/security`**
- Dart consumer: `lib/core/utils/security_lifecycle_mixin.dart`
- Native provider: `android/app/src/main/kotlin/com/example/cryptransfer/MainActivity.kt`
- Methods:
  - `isFlagSecureActive()` → returns `(flags & FLAG_SECURE) != 0` (boolean)
    - Used to verify window-level screenshot blocking before 64 KB file chunk reads
  - `clearSession()` → triggers `System.gc()` (no-op for native key material; all crypto runs in Dart)

**MethodChannel: `com.example.cryptransfer/file`**
- Dart consumer: `lib/presentation/receiver/decrypt_screen.dart` (_saveAndWipe)
- Native provider: `MainActivity.kt`
- Methods:
  - `saveToDownloads(fileName: String, bytes: ByteArray)` → saves to public Downloads folder
    - Android 10+ (API 29+): MediaStore.Downloads (no WRITE_EXTERNAL_STORAGE permission needed)
    - Android <10 (API 28-): Direct FileOutputStream (requires WRITE_EXTERNAL_STORAGE, declared in manifest with maxSdkVersion="28")
    - Runs on background thread to prevent UI blocking

## Security-Sensitive Integrations

**Firestore Security Rules:**
- Location: `firestore.rules`
- Enforces:
  - Authentication check (`isAuthenticated()`) on all reads/writes
  - Ownership verification (`isOwner(uid)`) for user documents and personal subcollections
  - Admin override function (`isAdmin()`) for dashboard access
  - Role-based access: Sender/receiver role in `transfers` and `handshakes` collections
  - Immutability: `audit_logs` and `rsa_key_manager` are append-only (update: false)
  - Atomic WriteBatch transactions: `selectSenderHandshake()` writes receiver doc + handshakes doc in one commit

**Encryption & Key Management:**
- RSA 2048-bit key generation: `EncryptionService.generateRsaKeyPairSync()` (via PointyCastle in `compute()` isolate)
- AES-256-GCM encryption/decryption: `runAesGcmEncrypt()`, `runAesGcmDecrypt()` (PointyCastle `GCMBlockCipher(AESEngine())` in `compute()` isolates)
- Secure random: `EncryptionService.secureRandomBytes()` (via `Random.secure()`)
- Private key storage: `flutter_secure_storage` (platform keystore encryption)
- Public key exchange: Firestore `handshakes` collection (no TLS interception risk; Firestore rules enforce role ownership)

**Kill-Switch & Session Wipe:**
- SessionManager → EncryptionService reactive binding: `EncryptionService.bindSession(stateStream, uid)` listens to `SessionManager.stateStream` and auto-calls `closeReceiverSession(uid)` on `SessionState.terminated`
- closeReceiverSession flow:
  1. Delete `publicKey` from `users/{uid}` doc
  2. Wipe RSA private key from `flutter_secure_storage`
  3. Batch-delete `handshakes` docs (WHERE `receiverId==uid`)
  4. Batch-delete notifications (WHERE `toUserId==uid` and `type=='rsa_key_received'`)
  5. Write `kill_switch` audit log
  6. Call `SecurityLifecycleMixin.requestNativeClear()` → `clearSession` MethodChannel for Kotlin `System.gc()` hint
  7. Wipe all Uint8List buffers via `SecurityLifecycleMixin.wipeAll()` (zero-fill + deregister)

**Android Security Hardening:**
- FLAG_SECURE: `MainActivity.onCreate()` sets `window.addFlags(LayoutParams.FLAG_SECURE)` globally for all Flutter screens
  - Blocks task-switcher thumbnails and screenshot capture at the window manager level
  - Applies to every screen without per-screen changes
- R8 minification: Release builds enable `isMinifyEnabled = true`, `isShrinkResources = true`
  - Reduces attack surface by obfuscating crypto class names and sensitive logic
  - ProGuard keep rules preserve Flutter, Firebase, PointyCastle, and Kotlin stdlib

## File Transfer Payload Path

1. **Sender:**
   - `SenderScreen._encryptFile()` reads file via `TransferService.resolve()` (64 KB chunked reads for memory stability)
   - `SenderScreen._encryptFile()` encrypts plaintext via `compute(runAesGcmEncrypt, [plaintext, key, iv])` (isolate-based AES-256-GCM)
   - `TransferProgressScreen._startUpload()` uploads ciphertext to Firebase Storage at `transfers/{transferId}/encrypted_file`

2. **Receiver:**
   - `DecryptScreen` downloads ciphertext from Firebase Storage
   - `DecryptScreen._decrypt()` decrypts via `compute(runAesGcmDecrypt, [ciphertext, key, iv])`
   - `DecryptScreen._saveAndWipe()` calls MethodChannel `saveToDownloads(fileName, bytes)` to persist plaintext to device Downloads folder
   - Plaintext is immediately wiped via `SecurityLifecycleMixin.wipeAll()` after save
