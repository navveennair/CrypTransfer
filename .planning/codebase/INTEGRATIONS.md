## Data Storage

**Databases:**

- **Cloud Firestore** (Primary real-time document database)
  - Client: cloud_firestore 6.3.0
  - Project: `cryptransfer-96e9f` (from `lib/firebase_options.dart`)
  - Connection: Auto-initialized via `Firebase.initializeApp(options: DefaultFirebaseOptions.currentPlatform)` in `lib/main.dart`
  - Firestore Security Rules: `firestore.rules` (deployed via `firebase.json`)
  
  **Collections (from `lib/core/constants/firebase_constants.dart`):**
  - `users/{uid}` - User profiles (username, email, phone, publicKey, isReadyToReceive, selectedSenderUid, isAdmin)
    - Subcollections:
      - `users/{uid}/notifications` - In-app alerts (rsa_key_received, fromUserId, toUserId, read)
      - `users/{uid}/audit_logs` - Per-user immutable transfer audit trail (senderId, receiverId, participants, security lifecycle events)
      - `users/{uid}/rsa_key_manager` - Append-only RSA key lifecycle log (action: generated/regenerated/deleted)
      - `users/{uid}/profile` - Security/UX preferences (biometricGateEnabled, themeMode, keyVaultCreatedAt)
      - `users/{uid}/friendships` - Connection status to other users (status: accepted/pending)
  
  - `transfers/{transferId}` - Active transfer metadata (senderId, receiverId, encryptedAESKey, iv, fileName, fileSize, status, participants, receiverStatus, cleanup_initiated, createdAt)
  
  - `transfer_logs/{logId}` - Global audit trail (senderId, receiverId, participants, timestamp, event type)
  
  - `handshakes/{docId}` - RSA key handshake signaling (status: pending_sent/handshake_complete, fromUserId, toUserId, publicKey)
  
  - `neutral_handshakes` - Handshake routing layer (planned)
  
  - `security_audit_log` - Platform security events (admin-only)
  
  **Usage Patterns:**
  - Direct `FirebaseFirestore.instance` in repositories: `lib/data/repositories/transfer_repository.dart`, `lib/data/repositories/auth_repository.dart`, `lib/data/repositories/key_repository.dart`, `lib/data/repositories/handshake_repository.dart`
  - StreamBuilders in UI for real-time updates: `lib/presentation/receiver/receiver_screen.dart` (_transferStream), `lib/presentation/home/home_screen.dart` (Recent Transfers)
  - Batch operations for atomic multi-doc writes: `AuthRepository.register()` (user + profile), `KeyRepository.selectSenderHandshake()` (user + rsa_key_transfers), `EncryptionService.closeReceiverSession()` (cleanup delete batch)

**File Storage:**

- **Firebase Cloud Storage** (Encrypted file archive)
  - Client: firebase_storage 13.2.0–13.4.0
  - Storage bucket: `cryptransfer-96e9f.firebasestorage.app` (from `lib/firebase_options.dart`)
  - Path structure: `transfers/{transferId}/encrypted_file`
  - Max file size: 100 MB enforced in `lib/core/constants/firebase_constants.dart` (maxDownloadBytes)
  - Upload flow: `lib/presentation/sender/sender_screen.dart` → `_encryptFile()` → `TransferRepository.uploadAndCreate()` streams progress (0.0–1.0)
  - Download flow: `lib/presentation/receiver/decrypt_screen.dart` → reads via Firebase Storage reference
  - Cleanup: `lib/presentation/receiver/receiver_end_session_screen.dart` → `_endSession()` deletes Storage file via `storage.ref(...).delete()`

**Secure Local Storage:**

- **Flutter Secure Storage** (Device keystore for RSA keys)
  - Client: flutter_secure_storage 10.0.0
  - Backend: Android Keystore (hardware-backed if available)
  - Key names (from `lib/core/constants/firebase_constants.dart`):
    - `rsa_private_key` - User's RSA-2048 private key (stored encrypted by OS)
    - `rsa_public_key_{uid}` - Cached peer public keys
  - Write: `lib/data/services/encryption_service.dart` → `generateAndStoreKeyPair()` after RSA key generation in `compute()` isolate
  - Read: `lib/data/repositories/key_repository.dart` and `lib/data/services/encryption_service.dart` → `loadPrivateKey()` for decryption
  - Wipe: `EncryptionService.closeReceiverSession()` → `_secure.delete(key: FirebaseConstants.privateKeyStorageKey)` on receiver kill-switch

**Caching:**

- In-memory only via Dart isolate `compute()` calls and cached stream fields
- No persistent local cache beyond Secure Storage for RSA keys
- File buffers: 64 KB chunks via `lib/data/services/transfer_service.dart` (TransferService.resolve) to minimize RAM footprint

## Monitoring & Observability

**Logs:**

- **Audit Trail via Firestore** - Transfer and security lifecycle events logged to `transfer_logs` and per-user `audit_logs`
  - Service: `lib/data/services/transfer_log_service.dart` → `writeAuditLog()`
  - Immutable: `firestore.rules` forbids updates to audit_logs (append-only)
  - Events tracked:
    - `encryption_initiated` - Sender begins plaintext encryption
    - `encryption_completed` - Ciphertext uploaded to Storage
    - `handshake_complete` - Receiver authorized sender (RSA key exchange)
    - `decryption_initiated` - Receiver starts AES decryption
    - `decryption_completed` - Plaintext saved to device
    - `cleanup_initiated` - Receiver triggered zero-wipe
    - `session_closed` - Kill-switch cleanup executed
  - Fields: senderId, receiverId, participants (array), timestamp
  - Consumer: `lib/presentation/admin/admin_dashboard_screen.dart` → aggregates for analytics
  - Accessible: Sender/receiver via personal audit_logs; admin via global transfer_logs

- **Console Logging** - Stdlib `print()` during development (disabled in production via R8 minification)

## Security Integration Points

**Android Native Bridge (FLAG_SECURE & MethodChannels):**

- **FLAG_SECURE Window Flag:**
  - Kotlin: `MainActivity.onCreate()` calls `window.addFlags(LayoutParams.FLAG_SECURE)` in `android/app/src/main/kotlin/com/example/cryptransfer/MainActivity.kt`
  - Effect: Blocks task-switcher screenshots and screen captures at Android window level; applies to all Flutter screens
  - Dart query: `SecurityLifecycleMixin.isFlagSecureActive()` checks status before 64 KB chunk reads

- **MethodChannel: `com.example.cryptransfer/security`**
  - Handler: `MainActivity.configureFlutterEngine()` registers method handler
  - Methods:
    - `isFlagSecureActive` → returns `(flags & FLAG_SECURE) != 0` to Dart
    - `clearSession` → calls `System.gc()` hint (no key bytes held natively; all crypto in Dart compute() isolates)
  - Consumer: `lib/core/utils/security_lifecycle_mixin.dart` → invokes before sensitive operations

- **MethodChannel: `com.example.cryptransfer/file`**
  - Handler: `MainActivity.configureFlutterEngine()` registers method handler
  - Methods:
    - `saveToDownloads(fileName, bytes)` → saves to public Downloads folder
      - Android 10+ (API 29+): MediaStore.Downloads (no WRITE_EXTERNAL_STORAGE needed)
      - Android <10 (API 28-): direct FileOutputStream (needs WRITE_EXTERNAL_STORAGE, declared with maxSdkVersion="28")
  - Consumer: `lib/presentation/receiver/decrypt_screen.dart` → `_saveAndWipe()` saves plaintext after decryption

**Cryptography Stack:**

- **PointyCastle 4.0.0** - RSA-2048 key generation and AES-256-GCM encryption
  - RSA: Fortuna PRNG for secure randomness, 2048-bit key size
  - AES: 256-bit key, 96-bit IV, GCM mode (authenticated encryption) via `GCMBlockCipher`
  - Isolation: All crypto in `compute()` isolates (background isolates) to prevent UI thread blocking
  - Flow: Plaintext → `registerBuffer()` (safety net) → `compute(runAesGcmEncrypt)` → Ciphertext → `fillRange(0)` + `unregisterBuffer()` (eager zero-wipe of main isolate copy)

- **Secure Storage** - Device keystore for RSA private keys
  - `flutter_secure_storage` encrypts keys at OS level (Android Keystore, hardware-backed if available)
  - Wipe: `closeReceiverSession()` deletes private key from keystore on receiver kill-switch

- **Session Kill-Switch (SessionManager + EncryptionService reactive binding):**
  - SessionManager: `lib/core/utils/session_manager.dart` owns SessionState (open/locked/decrypting/terminated)
  - Stream-driven cleanup: `SessionManager.stateStream` emits SessionState transitions
  - Reactive binding: `EncryptionService.bindSession(stateStream, uid)` auto-calls `closeReceiverSession(uid)` on `SessionState.terminated`
  - Zero-remanence: Batch-delete rsa_key_transfers, batch-delete notifications, delete Firestore doc, wipe buffer registry on `SecurityLifecycleMixin.wipeAll()`
