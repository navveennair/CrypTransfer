## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Silent flag reset failures | Buttons with state flags that aren't reset after async operations stay disabled forever | blocking | Use try-finally or delayed callback to guarantee flag reset after every operation |
| Biometric gate without error surfacing | BiometricHelper.authenticate() failures not caught/surfaced leaves screens stuck with no user feedback | blocking | Wrap all biometric calls in try-catch that shows error snackbar or falls back gracefully |
| Manual role selection instead of automatic | Flow assumes receiver manually selects sender, but neutral handshake provides pre-filled sender UID that should trigger automatic connection | blocking | When receiver toggles readiness ON and preFilledSenderUid is set, automatically call `_onSenderSelected()` without waiting for user action |
