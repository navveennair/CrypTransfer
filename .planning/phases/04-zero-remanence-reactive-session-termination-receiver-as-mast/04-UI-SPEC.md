## Spacing Scale

All values from the existing codebase — copied verbatim from `EndSessionScreen` and `shared_widgets.dart`.

| Token | Value | Usage |
|-------|-------|-------|

## Color

GitHub Dark palette as declared in `CLAUDE.md` and confirmed in `lib/app_theme.dart`.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0F172A` (`AppTheme.darkBg`) | Scaffold background for both new screens |
| Secondary (30%) | `#1E293B` (`AppTheme.darkSurface`) | Summary card, step tile pending state (`cs.surfaceContainerLow`) |
| Accent (10%) | `cs.primary` (seed: `#F59E0B` gold) | Active step tile border + background, CircularProgressIndicator, summary icon tint |
| Destructive | `Colors.red.shade700` | "End Session" CrypButton on ReceiverEndSessionScreen; warning banner border/text |

Accent reserved for: active step tile background (`cs.primaryContainer` at 0.5 alpha), active step indicator (CircularProgressIndicator), and the "End Session" CrypButton color override (`Colors.red.shade700` — not the primary accent; red is used specifically to signal destructive intent).

Semantic state colors (not accent — copy verbatim from EndSessionScreen):
- Done state: `Colors.green.shade600` (tile bg alpha 0.1, icon), `Colors.green.shade700` (text, "Session Ended" heading), `Colors.green.shade300` (tile border), `Colors.green.shade200` (done summary card border)
- Warning banner: `Colors.red.shade300` (border), `Colors.red.shade700` (icon + text), `Colors.red` at alpha 0.08 (fill)
- Error inline: `cs.errorContainer` at alpha 0.5 (bg), `cs.error` (icon + text)
- Done summary card: `Colors.green` at alpha 0.06 (fill), `Colors.green.shade200` (border)
- Done success circle: `Colors.green.shade600` (fill), white icon

SenderSessionEndedScreen uses the same green palette for both checklist sections (both sections are confirmations, not destructive). No red used on `SenderSessionEndedScreen`.

## Screen Contracts

### Screen 1: ReceiverEndSessionScreen

**Location:** `lib/presentation/receiver/receiver_end_session_screen.dart` (new file)
**Pattern:** Structural copy of `EndSessionScreen` with receiver-specific step list and cleanup sequence.

#### AppBar
- Title: `'Session Summary'` — Poppins w600, centered.
- `automaticallyImplyLeading: _phase != _Phase.cleaning` — hides back arrow during cleanup.

#### Phase: ready (initial state)

**Primary focal point:** The warning banner (red border + icon) draws the eye first on arrival, establishing the destructive intent before the user reads the summary card. The red `CrypButton` below reinforces the action's weight. Reading order: summary card (context) → warning banner (consequence) → CrypButton (action).

**Summary card** (`cs.surfaceContainerLow` bg, `cs.outlineVariant` border, `BorderRadius.circular(16)`, `padding: all(16)`):
- Header row: `Icons.summarize_rounded` (cs.primary, size 20) + `'Transfer Summary'` (Poppins w600, 14px)
- `_SummaryRow` entries (icon size 17, label col width 68, font 14px):
  - `Icons.insert_drive_file_rounded` / `'File'` / `widget.fileName` / color `cs.primary`
  - `Icons.data_usage_rounded` / `'Size'` / formatted fileSize / color `cs.primary`
  - `Icons.calendar_today_rounded` / `'Date'` / formatted date / color `cs.primary`
  - `Icons.access_time_rounded` / `'Time'` / formatted time / color `cs.primary`
  - `Divider(height: 24)`
  - `Icons.upload_rounded` / `'Sender'` / `'@{senderUsername}'` / color `Colors.indigo.shade600`
  - `Icons.download_rounded` / `'Receiver'` / `'@{receiverUsername}'` / color `Colors.deepPurple.shade600`

**Warning banner** (`Colors.red` alpha 0.08 bg, `Colors.red.shade300` border, `BorderRadius.circular(14)`, `padding: all(16)`):
- Icon: `Icons.warning_amber_rounded`, `Colors.red.shade700`, size 22
- Title: `'Permanent Deletion Warning'` — Poppins w600, 14px, `Colors.red.shade800`
- Body: `'Once the session ends, all transfer data will be permanently deleted — the encrypted file, RSA keys, and transfer record cannot be recovered.'` — 14px, `Colors.red.shade800`, height 1.5

**Error container** (shown only on retry, after a failed cleanup attempt):
- `cs.errorContainer` alpha 0.5 bg, `BorderRadius.circular(10)`, `padding: all(12)`
- `Icons.error_outline` size 16, `cs.error`
- Error message text: 13px, `cs.error`

**CrypButton** (primary action):
- `icon: Icon(Icons.lock_clock_rounded)`
- `label: Text(_error != null ? 'Retry End Session' : 'End Session')`
- `color: Colors.red.shade700`
- `onPressed: _endSession`

#### Phase: cleaning

**Heading block** (centered, `SizedBox(height: 24)` top spacer):
- Primary: `'Ending Session…'` — Poppins w700, 22px, centered
- Subtitle: `'Securely wiping all transfer data.'` — `cs.onSurfaceVariant`, centered

**Step list** (`SizedBox(height: 48)` before list): 4 `_CleanStepTile` entries, `EdgeInsets.only(bottom: 8)` gap between tiles.

ReceiverEndSessionScreen step list (4 steps matching D-03):

| Index | Icon | Label |
|-------|------|-------|
| 0 | `Icons.receipt_long_rounded` | `'Write immutable audit log'` |
| 1 | `Icons.cloud_off_rounded` | `'Delete encrypted file from storage'` |
| 2 | `Icons.delete_forever_rounded` | `'Delete transfer record and handshake'` |
| 3 | `Icons.person_off_rounded` | `'Wipe RSA keys from device and Firestore'` |

**_CleanStepTile visual states** (copy verbatim from EndSessionScreen lines 599–675):
- Pending: `cs.surfaceContainerLow` bg, `cs.outlineVariant` border, `Icons.radio_button_unchecked` (`cs.outlineVariant`, size 22)
- Active: `cs.primaryContainer` alpha 0.5 bg, `cs.primary` border alpha 0.4, `CircularProgressIndicator(strokeWidth: 2.5, color: cs.primary)` (20x20 SizedBox)
- Done: `Colors.green` alpha 0.1 bg, `Colors.green.shade300` border, `Icons.check_circle_rounded` (`Colors.green.shade600`, size 22)
- Tile border-radius: `BorderRadius.circular(12)`
- Tile animation: `AnimatedContainer(duration: Duration(milliseconds: 250))`
- Label text: 14px; color `cs.onSurfaceVariant` when pending; `fg` (green/primary) when active/done; weight `FontWeight.w600` when active/done, normal when pending.

#### Phase: done

**Done view** (copy verbatim from EndSessionScreen lines 475–546):
- `SizedBox(height: 32)` top spacer
- `ScaleTransition` with `Curves.elasticOut`, `AnimationController(duration: 700ms)`:
  - `Container(width: 96, height: 96, shape: BoxShape.circle, color: Colors.green.shade600)`
  - `Icon(Icons.shield_rounded, color: Colors.white, size: 52)`
- `SizedBox(height: 24)`
- `'Session Ended'` — Poppins w600, 24px, `Colors.green.shade700`, centered
- `SizedBox(height: 8)`
- `'All transfer data has been permanently deleted.\nA minimal audit log has been retained.'` — `cs.onSurfaceVariant`, height 1.6, centered
- `SizedBox(height: 32)`
- Green summary container (`Colors.green` alpha 0.06, `Colors.green.shade200` border, `BorderRadius.circular(14)`, `padding: all(16)`):
  - `_DoneStepRow` for each of the 4 completed steps
- `SizedBox(height: 32)`
- CrypButton: `icon: Icon(Icons.home_rounded)`, `label: Text('Back to Home')`, `color: Colors.green.shade600`, `onPressed: Navigator.pushAndRemoveUntil(HomeScreen, (_) => false)`

#### Back-nav contract
- `PopScope(canPop: _phase == _Phase.ready)` — blocks back during `cleaning` and `done` phases.

### Screen 2: SenderSessionEndedScreen

**Location:** `lib/presentation/sender/sender_session_ended_screen.dart` (new file)
**Pattern:** Static read-only screen. No cleanup sequence, no step animation. Two checklist sections.

This screen is NOT a copy of EndSessionScreen's cleaning flow. It is a simpler layout: two static
sections showing what was cleaned, displayed after D-10 edge-case check completes.

#### AppBar
- Title: `'Session Ended'` — Poppins w600, centered.
- No back arrow: `automaticallyImplyLeading: false` (or `PopScope(canPop: false)` wrapping Scaffold).

#### Layout (SingleChildScrollView, `EdgeInsets.fromLTRB(24, 16, 24, 32)`)

**Top spacer:** `SizedBox(height: 24)`

**Success header block** (centered):
- `Container(width: 80, height: 80, shape: BoxShape.circle, color: Colors.green.shade600)`
- `Icon(Icons.shield_rounded, color: Colors.white, size: 44)` — slightly smaller than ReceiverEndSessionScreen's 52px since there is no ScaleTransition here
- `SizedBox(height: 16)`
- `'Session Ended'` — Poppins w600, 22px, `Colors.green.shade700`, centered
- `SizedBox(height: 8)`
- `'The receiver has completed secure cleanup.'` — `cs.onSurfaceVariant`, 14px, centered

**SizedBox(height: 32)**

**Section 1: "Receiver cleaned up:"**
- Section label: `'Receiver cleaned up:'` — Poppins w600, 14px, `cs.onSurfaceVariant`
- `SizedBox(height: 8)`
- Green checklist container (`Colors.green` alpha 0.06, `Colors.green.shade200` border, `BorderRadius.circular(14)`, `padding: all(16)`):
  - `_DoneStepRow(icon: Icons.receipt_long_rounded, label: 'Audit log written to both users')`
  - `_DoneStepRow(icon: Icons.cloud_off_rounded, label: 'Encrypted file deleted from storage')`
  - `_DoneStepRow(icon: Icons.delete_forever_rounded, label: 'Transfer record deleted')`
  - `_DoneStepRow(icon: Icons.person_off_rounded, label: 'RSA key wiped from receiver device')`

**SizedBox(height: 16)**

**Section 2: "Your device cleaned up:"**
- Section label: `'Your device cleaned up:'` — Poppins w600, 14px, `cs.onSurfaceVariant`
- `SizedBox(height: 8)`
- Green checklist container (same styling as Section 1):
  - `_DoneStepRow(icon: Icons.memory_rounded, label: 'AES key zeroed from memory')`
- Note: This section is shown only after the D-10 edge-case Firestore check completes. During the check (async in `initState` or `_checkAndMarkDone()`), the AES row may show a loading state before turning green. Implementation detail — see RESEARCH.md D-10 guidance.

**SizedBox(height: 32)**

**CrypButton** (single action):
- `icon: Icon(Icons.home_rounded)`
- `label: Text('Back to Home')`
- `color: Colors.green.shade600`
- `onPressed: Navigator.pushAndRemoveUntil(HomeScreen, (_) => false)`

#### Back-nav contract
- `PopScope(canPop: false)` — no back navigation. Only exit is "Back to Home".

## Interaction States

### ReceiverEndSessionScreen

| State | Trigger | Visual |
|-------|---------|--------|
| ready | Initial navigation arrival | Summary card + warning banner + "End Session" CrypButton |
| cleaning | "End Session" pressed | Step list animates; back-nav blocked; AppBar back arrow hidden |
| done | All 4 steps complete | Green shield animation + "Back to Home" CrypButton |
| error | Any step throws | Returns to `ready` phase; error container appears above CrypButton; CTA label changes to `'Retry End Session'` |

### SenderSessionEndedScreen

| State | Trigger | Visual |
|-------|---------|--------|
| loading (AES check) | `initState` / D-10 async check | Section 2 AES row shows pending indicator before check resolves |
| complete | D-10 check done | Both sections show all rows as green done |

No user-triggered state transitions on SenderSessionEndedScreen — it is display-only.
