```dart
import 'package:flutter/material.dart';
import '../../data/repositories/auth_repository.dart';
import '../../data/models/user_model.dart';

/// Route-level guard for the /admin-dashboard route.
///
/// Streams [AuthRepository.streamUserProfile] and:
/// - Shows a loading scaffold while the stream is pending.
/// - Redirects to '/' with an 'Access denied' SnackBar if the user is not an admin.
/// - Redirects silently to '/' if no user is authenticated.
/// - Renders [child] when [UserModel.isAdmin] is true.
///
/// All navigation uses [WidgetsBinding.instance.addPostFrameCallback] to
/// avoid "setState called during build" errors (D-01/D-02/D-03).
class AdminGuard extends StatelessWidget {
  final Widget child;

  const AdminGuard({super.key, required this.child});

  @override
  Widget build(BuildContext context) {
    final cs = Theme.of(context).colorScheme;
    final authRepo = AuthRepository();
    final user = authRepo.currentUser;

    Widget _loadingScaffold() => Scaffold(
          backgroundColor: cs.surface,
          body: const Center(child: CircularProgressIndicator()),
        );

    // State A: no authenticated user — redirect silently, no SnackBar
    if (user == null) {
      WidgetsBinding.instance.addPostFrameCallback((_) {
        if (context.mounted) {
          Navigator.pushReplacementNamed(context, '/');
        }
      });
      return _loadingScaffold();
    }

    // States B/C/D: authenticated user — stream isAdmin status
    return StreamBuilder<UserModel?>(
      stream: authRepo.streamUserProfile(user.uid),
      builder: (context, snapshot) {
        // State B: stream loading
        if (!snapshot.hasData && !snapshot.hasError) {
          return _loadingScaffold();
        }

        // State C: error or non-admin — redirect with SnackBar
        if (snapshot.hasError || snapshot.data?.isAdmin != true) {
          WidgetsBinding.instance.addPostFrameCallback((_) {
            if (context.mounted) {
              ScaffoldMessenger.of(context).showSnackBar(
                const SnackBar(
                  content: Text('Access denied'),
                  duration: Duration(seconds: 3),
                ),
              );
              Navigator.pushReplacementNamed(context, '/');
            }
          });
          return _loadingScaffold();
        }

        // State D: admin confirmed — render child
        return child;
      },
    );
  }
}
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Route layer → AdminDashboard | /admin-dashboard route now enforced: non-admin users cannot reach AdminDashboard even via direct pushNamed or deep-link bypass |
| AdminGuard → Firestore users/{uid} | isAdmin check reads from Firestore — trust boundary is the Firestore security rules that govern who can write isAdmin=true |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-05-01 | Elevation of Privilege | /admin-dashboard route (CRITICAL) | mitigate | AdminGuard wraps the route at MaterialApp.routes level. Non-admin user receiving a hardcoded `pushNamed('/admin-dashboard')` will hit AdminGuard, see a spinner for < 1 frame, get 'Access denied' SnackBar, and be redirected to '/'. Child (AdminDashboard) is NEVER built for non-admins — per D-03. |
| T-11-05-02 | Spoofing | isAdmin Firestore field | accept | isAdmin is a Firestore server-side field. Client cannot forge it without server-side write permission. Firestore security rules (existing) restrict writes to isAdmin. AdminGuard reads via StreamBuilder — the value comes from the server-verified JWT. |
| T-11-05-03 | Information Disclosure | AdminGuard loading scaffold | accept | The loading scaffold shows only a CircularProgressIndicator — no admin UI, no data, no route information. Non-admin users see a spinner then redirect. Zero information leak. |
| T-11-05-04 | Denial of Service | addPostFrameCallback in AdminGuard | accept | Called once per route resolution. The callback is lightweight (SnackBar + pushReplacementNamed). No loop or retry risk. If the stream never emits (Firestore offline), the user sees an indefinite spinner — acceptable for admin tooling. |
| T-11-05-05 | Repudiation | Admin access control enforcement | mitigate | AdminGuard logs nothing itself, but `setUserActiveStatus()` (Plan 02) writes adminUid to the security_audit_log for every admin action. The guard prevents access; the audit log tracks actions after access. |
</threat_model>
