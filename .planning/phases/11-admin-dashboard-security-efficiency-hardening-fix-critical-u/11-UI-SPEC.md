# Phase 11 — UI Design Contract

> Visual and interaction contract for Phase 11: Admin Dashboard Security & Efficiency Hardening.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Scope note:** This is a hardening-only phase. No new screens, no redesign. All UI changes
> are minimal: error states, loading states, one new route-guard widget, ConnectionNodeMap
> FutureBuilder conversion, and TransferVolumeChart real-data axis labels. Every new widget
> must blend into the existing admin glassmorphic dark theme without introducing new tokens.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (Flutter Material 3 + manual design system) |
| Preset | not applicable |
| Component library | Material 3 via `AppTheme.dark` (`ThemeData.dark(useMaterial3: true)`) |
| Icon library | Material Icons (built-in) |
| Font | Poppins via `google_fonts` (pre-configured in `AppTheme`) |

**Source:** `lib/app_theme.dart` — all admin widgets already consume `AppTheme.dark` via the
`Theme(data: AppTheme.dark, ...)` wrapper in `AdminDashboard.build()`. New widgets must not
introduce any `ThemeData` override or hardcoded color.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon badge padding, tight label gaps |
| sm | 8px | Icon-to-text gap, row separators |
| md | 16px | Card internal padding, list separators |
| lg | 24px | Section padding, list top/bottom padding |
| xl | 32px | Section gaps in analytics tab |
| 2xl | 48px | — (not used in admin layer) |
| 3xl | 64px | — (not used in admin layer) |

Exceptions:
- `ConnectionNodeMap` grid: `crossAxisSpacing: 16`, `mainAxisSpacing: 16` (matches existing `childAspectRatio: 0.8` contract — preserve as-is)
- `AdminGuard` loading scaffold body: centered with no padding (full-screen `CircularProgressIndicator` is the only content)
- `TransferVolumeChart` container: `EdgeInsets.fromLTRB(16, 24, 24, 16)` — existing non-uniform padding, preserve to avoid chart clipping

| Role | Style Token | Size | Weight | Line Height | Usage |

## Color

All colors resolved through `Theme.of(context).colorScheme` from `AppTheme.dark`. Hex values
listed for reference only — executors must use `cs.*` tokens, not hardcoded hex.

| Role | Token | Resolved Hex (dark) | Usage |
|------|-------|---------------------|-------|
| Dominant (60%) | `cs.surface` | `#1E293B` | Scaffold background, `GlassContainer` base tint |
| Secondary (30%) | `cs.onSurface` / `cs.outline` | `#F8FAFC` / `#334155` | Text, card borders, subtle separators |
| Accent (10%) | `cs.primary` | Gold (Material seed `#CA8A04`) | Stat card icons, active node borders, chart line, tab indicator, AppBar title, active handshake icon |
| Destructive | `cs.error` | Material M3 error red | `hasError` branch text, revoked user border, critical security event icons |

**AdminGuard loading state:** `cs.surface` scaffold + `CircularProgressIndicator()` with no explicit color (inherits theme primary).

**AdminGuard redirect state:** Brief `cs.surface` scaffold + `CircularProgressIndicator()` displayed only during `addPostFrameCallback` frame — never shows error color, because the redirect happens immediately.

Accent reserved for:
- Chart line and gradient fill (TransferVolumeChart)
- Tab bar indicator line and selected tab label
- Active node tile border in ConnectionNodeMap
- Stat card icons (TRANSFERS card uses `cs.primary`; TOTAL NODES uses `cs.secondary`)
- Active handshake row icon in `_buildActiveSessionsList`
- AppBar title text (`CrypTransferAdmin`)

**`cs.secondary` (TOTAL NODES stat card icon, `_PulseIndicator` in handshake rows):** Must not be used for error states.

## Component Contracts

### 1. AdminGuard (`lib/presentation/admin/admin_guard.dart`) — NEW

Three render states:

**State A — Not logged in (no `currentUser`):**
- `Scaffold(backgroundColor: cs.surface, body: Center(child: CircularProgressIndicator()))`
- Navigation deferred via `addPostFrameCallback` → `Navigator.pushReplacementNamed(context, '/')`
- No SnackBar shown (user was never authenticated; redirect is silent)

**State B — Stream loading (`!snapshot.hasData && !snapshot.hasError`):**
- Identical scaffold as State A: full-screen centered `CircularProgressIndicator`
- Duration: Firestore stream first emission only (typically < 500ms on mobile); no timeout needed

**State C — Access denied (`isAdmin != true` or `snapshot.hasError`):**
- Same `Scaffold + CircularProgressIndicator` scaffold as State A (shown only during `addPostFrameCallback` frame)
- `ScaffoldMessenger.of(context).showSnackBar(SnackBar(content: Text('Access denied'), duration: Duration(seconds: 3)))` — 3-second duration (Claude's discretion)
- `Navigator.pushReplacementNamed(context, '/')` immediately after SnackBar is queued
- SnackBar uses default Material SnackBar styling (no custom background); the brief scaffold does not expose any admin UI

**State D — Access granted (`isAdmin == true`):**
- Returns `child` directly; AdminGuard renders as zero-overhead passthrough

**Interaction contract:**
- AdminGuard must not render the `child` (AdminDashboard) even briefly before the stream resolves
- `addPostFrameCallback` is mandatory for all navigation calls inside the build method
- No back-navigation is possible after redirect (pushReplacementNamed replaces the route)

### 2. hasError branches — ALL admin StreamBuilders

**Standard error widget (D-10, used in all locations except `_buildSummaryCards`):**
```
Center(
  child: Text(
    'Error loading data',
    style: TextStyle(color: cs.error),
  ),
)
```

**Placement order inside every StreamBuilder builder function:**
1. `connectionState == ConnectionState.waiting` → loading widget
2. `snapshot.hasError` → error widget (BEFORE `!snapshot.hasData`)
3. `!snapshot.hasData` → loading/empty widget
4. `snapshot.data` access → data widget

**Locations requiring the hasError branch (all currently missing it):**

| Widget | Stream | Error Widget Type | Notes |
|--------|--------|-------------------|-------|
| `AdminDashboard._buildSummaryCards` outer `StreamBuilder<int>` | `streamTotalTransfers()` | `Row` of two `_SummaryCard(value: '–', color: cs.error)` | Must preserve Row layout; returning `Center` collapses the card row |
| `AdminDashboard._buildSummaryCards` inner `StreamBuilder<int>` | `streamTotalUsers()` | `_SummaryCard(value: '–', color: cs.error)` | Inner card only |
| `AdminDashboard._buildActiveSessionsList` `StreamBuilder<QuerySnapshot>` | `streamActiveHandshakesDetail()` | Standard `Center(Text('Error loading data'))` inside `GlassContainer` | Matches empty-state pattern already present |
| `SecurityPulseFeed` `StreamBuilder<QuerySnapshot>` | `streamSecurityAuditLog()` | Standard `Center(Text('Error loading data'))` | Full-tab widget; `Center` is safe |
| `UserManagementList` `StreamBuilder<List<UserModel>>` | `streamAllUsers()` | Standard `Center(Text('Error loading data'))` | Full-tab widget; `Center` is safe |
| `TransferVolumeChart` `StreamBuilder<QuerySnapshot>` | `streamTransferLogsDetail()` | `Center(Text('Error loading data'))` inside existing `Container(height: 200)` | Contained widget; `Center` inside fixed-height container is safe |

**`_buildSummaryCards` special case — error `_SummaryCard` spec:**
- `value: '–'` (en-dash, not hyphen)
- Icon: same icon as normal (`Icons.swap_horiz_rounded` for transfers, `Icons.hub_rounded` for nodes)
- `color: cs.error` (overrides normal `cs.primary`/`cs.secondary`)
- No additional error copy inside the card — the `'–'` value is sufficient signal

### 3. ConnectionNodeMap FutureBuilder (`lib/presentation/admin/widgets/connection_node_map.dart`) — MODIFIED

Widget type change: `StatelessWidget` → `StatefulWidget`.

**Three render states:**

**State A — Waiting (`connectionState == ConnectionState.waiting`):**
- `Center(child: CircularProgressIndicator())`
- Full-tab centered; no padding
- No text label alongside the spinner

**State B — Error (`snapshot.hasError`):**
- `Center(child: Text('Error loading data', style: TextStyle(color: cs.error)))`
- Full-tab centered

**State C — Empty (data is non-null but `List.isEmpty`):**
- `Center(child: Text('No network nodes found', style: TextStyle(color: cs.onSurface.withValues(alpha: 0.5))))`
- Style matches existing empty-state copy in `_buildActiveSessionsList`

**State D — Data (`snapshot.data` is non-null and non-empty):**
- `GridView.builder` with existing spec: `crossAxisCount: 3`, `crossAxisSpacing: 16`, `mainAxisSpacing: 16`, `childAspectRatio: 0.8`, `padding: EdgeInsets.all(20)`
- Each grid cell: `_NodeTile` (unchanged visual contract — see existing code)
- Max 50 items (`.limit(50)` in `fetchUserConnections()`)

**Refresh mechanism (Claude's discretion — include it):**
- `IconButton(icon: Icon(Icons.refresh_rounded, color: cs.onSurface.withValues(alpha: 0.6)), onPressed: _refresh)` in the top-right of the grid tab
- Appears only in State D (data visible) — not shown during loading or error
- Rendered as a `Stack` with the `GridView` below and a positioned `Align(alignment: Alignment.topRight, child: IconButton(...))` above, padding 8px from top-right
- `_refresh()` calls `setState(() { _futureConnections = _adminRepo.fetchUserConnections(); })`
- No loading overlay during refresh — the entire FutureBuilder re-enters State A (full-tab spinner) to prevent stale data display

**`_NodeTile` visual contract — unchanged from existing implementation:**
- Active node (`connectionCount > 0`): border `cs.primary.withValues(alpha: 0.5)`, icon `cs.primary`, badge `cs.secondary`
- Isolated node (`connectionCount == 0`): border `cs.outline`, icon `cs.onSurface.withValues(alpha: 0.1)`
- Status label: `'CONNECTED'` (active) or `'ISOLATED'` (isolated) — unchanged
- Badge font size: 8px bold on `cs.onSecondary` background — unchanged

### 4. TransferVolumeChart — real data axis labels (`lib/presentation/admin/widgets/transfer_volume_chart.dart`) — MODIFIED

**Container spec (unchanged):** `height: 200`, `padding: EdgeInsets.fromLTRB(16, 24, 24, 16)`, `color: cs.surface`, `borderRadius: 24`, `border: Border.all(color: cs.outline)`.

**Chart states:**

**State A — Loading:** `Center(child: CircularProgressIndicator())` inside the existing fixed-height container.

**State B — Error (new):** `Center(child: Text('Error loading data', style: TextStyle(color: cs.error)))` inside the fixed-height container.

**State C — Data (real aggregation):**
- Always exactly 7 `FlSpot` values, X from 0.0 to 6.0, Y = transfer count for that day (0 if no transfers)
- X-axis 0 = today minus 6 calendar days (local time), X-axis 6 = today

**Line chart spec (keep existing, add bottom titles):**
- `isCurved: true`, `barWidth: 4`, `isStrokeCapRound: true`, `dotData: FlDotData(show: false)` — all unchanged
- Line color: `cs.primary` — unchanged
- Below-bar gradient: `cs.primary.withValues(alpha: 0.3)` → `cs.primary.withValues(alpha: 0.0)` — unchanged
- `gridData: FlGridData(show: false)` — unchanged
- `borderData: FlBorderData(show: false)` — unchanged

**Bottom axis titles (new, Claude's discretion — add for readability):**
```
titlesData: FlTitlesData(
  show: true,
  topTitles: AxisTitles(sideTitles: SideTitles(showTitles: false)),
  rightTitles: AxisTitles(sideTitles: SideTitles(showTitles: false)),
  leftTitles: AxisTitles(sideTitles: SideTitles(showTitles: false)),
  bottomTitles: AxisTitles(
    sideTitles: SideTitles(
      showTitles: true,
      reservedSize: 20,
      getTitlesWidget: (value, meta) {
        final day = cutoff.add(Duration(days: value.toInt()));
        final label = ['Mon','Tue','Wed','Thu','Fri','Sat','Sun'][day.weekday - 1];
        return Text(label, style: TextStyle(color: cs.onSurface.withValues(alpha: 0.5), fontSize: 10));
      },
    ),
  ),
),
```
- `reservedSize: 28` for bottom title area (to avoid chart line clipping below)
- Outer container height stays at 200px (the 28px is within the existing `fromLTRB(16, 24, 24, 16)` bottom padding)

**Y-axis max (Claude's discretion):**
- Dynamic: `max(countsByDay.values.reduce(max).toDouble(), 1.0)` with `+1` padding
- Prevents flat zero line when all days have 0 transfers (at least Y max = 1, giving a flat line at Y=0)
- Set via `LineChartData.maxY`
