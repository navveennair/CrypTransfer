| Firestore stream → SenderScreen | Handshake doc updates arrive via Firestore stream; the publicKey field is untrusted external data |
| SenderScreen → EncryptionService | Encrypted AES key is sent to receiver's RSA public key; if the key has changed, the wrong key receives the data |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-02 | Spoofing | _onHandshakeUpdate (sender_screen.dart) | mitigate | Capture previousPublicKey before setState; compare after setState; if key changed with non-null _encryptedAESKey, call _wipeSensitiveData() — prevents encrypted AES key from being sent to a changed (wrong) RSA public key. Mid-flight guard prevents wipe during active compute() isolate. |
| T-09-05 | Information Disclosure | Step 1 CrypButton re-pick (sender_screen.dart) | mitigate | Disable Browse Files CrypButton when _fileEncrypted=true; require explicit "Change File" → AlertDialog confirmation → _wipeSensitiveData() before new file pick. Prevents silent loss of encrypted state without user awareness. |
</threat_model>
