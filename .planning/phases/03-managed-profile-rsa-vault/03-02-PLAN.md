## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-02-01 | Tampering | register() partial write | mitigate | WriteBatch ensures atomicity — if profile write fails, user doc write also fails; no orphaned user docs without profile |
| T-03-02-02 | Tampering | signInWithGoogle() partial write | mitigate | Same WriteBatch pattern; `gBatch.commit()` is atomic |
| T-03-02-03 | Information Disclosure | profile/preferences initial values | accept | Initial values (biometricGateEnabled=false, themeMode='dark', nulls) contain no sensitive data; safe to write atomically |
| T-03-02-04 | Denial of Service | Pre-Phase-03 users missing profile doc | mitigate | `updateLastVaultAccess()` (added in Plan 03) uses `set(merge: true)` — lazy creation on first vault access |
