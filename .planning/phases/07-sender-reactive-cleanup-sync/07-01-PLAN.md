```dart
/// Starts a 300-second safety timeout after the receiver saves the file.
/// If cleanup_initiated never fires (receiver crash / no connection), we auto-wipe
/// and navigate to SenderSessionEndedScreen to unblock the sender.
void _startCleanupTimeout() {
  _cleanupTimeoutTimer?.cancel(); // defensive: should not already be running
  _cleanupTimeoutTimer = Timer(const Duration(seconds: 300), () {
    if (!mounted || _senderWipeSent || _sessionEnded) return;
    _sessionEnded = true;
    wipeAll();
    if (mounted) {
      Navigator.pushReplacement(
        context,
        MaterialPageRoute(
          builder: (_) => SenderSessionEndedScreen(
            transferId: widget.transferId,
            fileName: widget.fileName,
            fileSize: widget.fileSize,
            receiverUsername: widget.receiverUsername,
            senderId: widget.senderId,
            receiverId: widget.receiverId,
            timeoutReason: 'Session ended by timeout — receiver did not complete cleanup',
          ),
        ),
      );
    }
  });
}
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Firestore snapshot → Timer cancel | Timer must not fire after navigation; mounted check + _sessionEnded/_senderWipeSent guards prevent double-wipe |
| Timer callback → Navigator | Timer callback runs on main isolate but screen may have disposed; mounted guard is mandatory |
| Back-navigation → dispose() | canPop=true after _done=true; user navigating back while timer is running triggers dispose() which must cancel timer before buffers are zeroed |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Denial of Service | _cleanupTimeoutTimer | mitigate | Cancel timer in dispose() — prevents use-after-dispose crash if user navigates away manually before timeout fires |
| T-07-02 | Elevation of Privilege | SenderSessionEndedScreen.timeoutReason | accept | timeoutReason is a static string set by local code, not derived from Firestore data; no injection risk |
| T-07-03 | Tampering | _senderWipeSent double-fire | mitigate | Existing _senderWipeSent guard already prevents re-entry; timer cancel in Turn 2 ensures timer does not race with the wipe already in progress |
| T-07-04 | Information Disclosure | Back-nav while timer running | mitigate | dispose() cancels timer and SecurityLifecycleMixin.wipeAll() zeroes all registered Uint8List buffers (encryptedBytes + aesKey) — no key leakage on back-navigation |
</threat_model>
