## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Kotlin ↔ Dart (MethodChannel) | Cross-language string-literal pair. `flutter analyze` does NOT verify equality across the boundary. A typo on either side produces silent runtime failure (security channel: invisible via `isFlagSecureActive()` safe-fallback; file channel: SnackBar at save time). |
| Local code ↔ Firebase Console state | `google-services.json` byte content is determined by Firebase Console state. Mismatch between Console-registered package_name and Gradle `applicationId` produces hard build failure. |
| Old install (com.example.cryptransfer) ↔ New install (com.navveennair.cryptransfer) | OS treats them as distinct apps. Old install may persist on device after new install — not a security risk, but a verification ambiguity. |
| Build artifacts (`build/`) ↔ runtime APK | Stale `BuildConfig.APPLICATION_ID` in `build/` could embed old package into a new APK if `flutter clean` is skipped. |
