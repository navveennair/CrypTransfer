## Validation Dimensions

### D1 — Google Sign-In happy path
- Trigger Google Sign-In on Login screen → Firebase Auth succeeds → `users/{uid}` doc created with `email`, `displayName`, `isAdmin: false`, `isReadyToReceive: false`

### D2 — Google Sign-In — existing user
- Repeat Google Sign-In with same account → no duplicate `users` doc created, existing doc preserved

### D3 — Disconnect deletes friendship + handshakes
- Two users with `friendships/{docId}` status=accepted + shared `handshakes` docs → Disconnect → friendship doc deleted, all shared `handshakes` docs deleted

### D4 — Theme persists across restart
- Select Dark Mode in onboarding → close app → reopen → `ThemeMode.dark` is active, onboarding does NOT show again

### D5 — Theme onboarding shown only once
- First login → onboarding shown → select theme → logout → re-login → onboarding NOT shown

### D6 — Form validation rejects invalid inputs
- Empty email → validation error shown
- Invalid email format → validation error shown
- Password < 8 chars → validation error shown
- Password with no digit → validation error shown

### D7 — Friends list shows accepted friends only
- Query `friendships` where `participants arrayContains uid AND status=accepted` → only accepted friends displayed in My Connections screen

### D8 — No regression on existing crypto transfer flow
- Existing sender/receiver flow unaffected: SessionManager, EncryptionService, kill-switch all pass
